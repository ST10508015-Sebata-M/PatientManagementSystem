# PatientManagementSystem
This is a Java console app I built for managing hospital patients — registering them, sorting out bed allocations and generating reports through a menu-driven system. I used inheritance to create an InPatient class that extends the base Patient class, plus encapsulation and method overriding to keep things clean and category-specific. It handles full CRUD on patient records with duplicate ID checks, manages a 4x5 bed layout for wards and includes sorting/reporting features built around a custom bubble sort. I wrote JUnit tests to cover CRUD, bed allocations, validation and sorting so I could actually trust the code was working. Hit a few bugs along the way (forgot the extends keyword at one point which broke my super() call lol) but got it sorted and did a final pass on comments so future me can actually understand past me's code.
